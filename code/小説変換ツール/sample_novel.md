# 異世界転生したら最強のチート猫だった件 ～魔王城でまったり昼寝生活～

```
トラックに轢かれて目覚めたら、なぜか魔王城に住み着く白猫に転生していた！？
モフモフの身体と規格外のチート魔法を武器に、今日も魔王の膝の上で二度寝を決める――！
笑いとモフモフが織りなす異世界スローライフファンタジー。
```

## プロローグ：目覚めたら猫でした

暖かい日差しと、心地よい絨毯の感触。  
ふと目を覚ますと、視界がいつもよりずっと低い。  

「にゃーん？」  

思わず声を出してみたら、自分の口から出たのは情けない猫の鳴き声だった。  
見下ろせば、ふわふわの白い前足。肉球は綺麗なピンク色をしている。  

（……えっ、俺、猫になってる！？）  

確か、深夜のコンビニ帰りに居眠り運転のトラックから小学生をかばって――そこまでは覚えている。  
どうやら絵に描いたような<ruby><rb>異世界転生</rb><rt>いせかいてんせい</rt></ruby>を果たしてしまったらしい。  

## 第1章：魔王様との出会い

「おい、こんな所に猫が迷い込んでいるぞ」  

部屋の重厚な扉が開き、漆黒のローブをまとった筋骨隆々の男が入ってきた。  
頭には禍々しい角、背中には黒い翼。どう見ても<ruby><rb>魔王</rb><rt>まおう</rt></ruby>その人である。  

普通の転生者なら腰を抜かすところだろうが、今の俺には抗えない本能があった。  
男の手から漂う、**干し肉の極上の香り**。  

「グルニャァ……（飯くれ）」  

俺はすり寄って頭をごつんと押し付けた。  
魔王は目を見張り、次の瞬間には相好を崩していた。  

「ぐっ……な、なんと愛らしい毛並みだ……！ 今日から貴様は我が城の<ruby><rb>最高名誉顧問猫</rb><rt>さいこうめいよこもんねこ</rt></ruby>だ！」  

世界を滅ぼす魔王が、あっさりとモフモフの軍門に降った瞬間だった。  

## 第2章：伝説の魔力、炸裂？

平和な昼寝ライフが始まったと思いきや、城に招かれざる客がやってきた。  
教会の放った<ruby><rb>勇者パーティー</rb><rt>ゆうしゃパーティー</rt></ruby>だ。  

「魔王、覚悟――って、なんだあの猫は？」  
「ふっ、油断するな。あれは魔王が飼う凶悪な魔獣に違いない！」  

昼寝を邪魔されて機嫌を損ねた俺は、軽くあくびをしながら前足をひと振りした。  

「ふにゃー（うるさい、あっち行け）」  

放たれたのは、猫パンチの軌跡を描く<ruby><rb>次元断裂衝撃波</rb><rt>ディメンション・スラッシュ</rt></ruby>。  
城の訓練場ごと勇者たちの武器が遥か彼方へと吹き飛んでいく。  

「「「バ、バケモノだーーー！！」」」  

脱兎のごとく逃げ出す勇者たちを見送りながら、俺は再び丸くなって目を閉じた。  
今日も魔王城は平和である。
