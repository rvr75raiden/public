# 小説フォーマット変換ツール (Pixiv & ハーメルン対応)

Markdown で執筆された小説原稿を、**Pixiv 小説特殊タグ** や **ハーメルン文章装飾タグ** にワンクリックで相互変換し、各投稿フォームへのコピペ準備を瞬時に行えるツールです。

---

## 🚀 主な機能・特徴

1. **2通りの使い方が可能**
   - **ブラウザ版 (`novel_converter.html` / `起動_小説変換ツール.bat`)**:
     - ダブルクリックするだけでブラウザ上で動作（インターネット不要・完全オフライン・安全）
     - ドラッグ＆ドロップまたはファイル選択で Markdown ファイルを瞬時に読み込み
     - 直接テキスト貼り付け・編集もリアルタイム変換
     - **「タイトル」「キャプション（あらすじ）」「本文」の個別ワンクリックコピーボタン**
     - **「全テキストコピー」「.txt 保存」ボタン**
     - ルビや章見出しが反映された「表示プレビュー」機能
     - 小説執筆者向けの文字数・原稿用紙換算枚数カウンター
   - **Python CLI版 (`novel_converter.py`)**:
     - コマンドラインから一発で `.txt` を出力
     - 複数話の一括変換・自動処理に最適

2. **変換ルール**
   - **タイトル**: `# タイトル` 行から抽出（投稿欄が分かれているため個別コピー可能）
   - **キャプション**: ```` で囲まれたブロックからあらすじ/キャプションとして抽出
   - **章（チャプター）タイトル**:
     - **Pixiv**: `## 章タイトル` ➔ `[newpage]\n[chapter:章タイトル]`
       *(※先頭章の改ページ有無は設定で切り替え可能)*
     - **ハーメルン**: `## 章タイトル` ➔ `《big》《b》■章タイトル《/b》《/big》《hr》`
   - **ルビ**:
     - Markdown: `<ruby><rb>親文字</rb><rt>ルビ</rt></ruby>`
     - **Pixiv**: `[[rb:親文字 > ルビ]]`
     - **ハーメルン**: `|親文字《ルビ》`
   - **装飾・記法**:
     - ハーメルン用太字: `**強調**` ➔ `《b》強調《/b》`
     - 行末の余分な空白除去、3行以上の連続空行の圧縮整理

```

## 📖 使い方

### 1. ブラウザで使う場合（おすすめ）
1. `起動_小説変換ツール.bat` または `novel_converter.html` をダブルクリックします。
2. ブラウザが開いたら、上部の枠に Markdown ファイル（`.md`）をドラッグ＆ドロップするか、「ファイルを選択」を押します。
   - 「📄 サンプル読み込み」ボタンを押すと、添付の『聖都の夜に魔剣は吠える 第7話』が即座に読み込まれます。
3. 右側のパネルで **「Pixiv 記法」** または **「ハーメルン 記法」** タブを選びます。
4. それぞれの投稿フォームに合わせて：
   - **「タイトルをコピー」** ➔ 投稿フォームのタイトル欄に貼り付け
   - **「キャプションをコピー」** ➔ 投稿フォームのキャプション（あらすじ）欄に貼り付け
   - **「本文をコピー」** ➔ 本文欄に貼り付け
5. 必要に応じて「💾 .txt 保存」でテキストファイルとしてダウンロードも可能です。

### 2. Python CLI で使う場合
```bash
# 基本使用法（Pixiv用とハーメルン用の両方を自動生成）
python novel_converter.py "パス/to/小説.md"

# 出力先フォルダを指定する場合
python novel_converter.py "パス/to/小説.md" -o "./output"

# Pixivのみ、またはハーメルンのみ出力する場合
python novel_converter.py "パス/to/小説.md" -t pixiv
python novel_converter.py "パス/to/小説.md" -t hameln
```
