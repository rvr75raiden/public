# 縦書文庫 (Vertical Novel Reader)

Web上のテキストやMarkdown原稿を、日本の伝統的な**縦組（縦書き）**で心地よく読むためのWebリーダーです。

外部CDNやサーバーに依存せず、ブラウザだけで快適に動作するスタンドアロン設計。ネット環境のないオフラインでも完全に動作します。

---

## 🌟 主な機能と特徴

### 1. 📖 本格的な縦組・横組リーダー
- **ワンタッチ縦横切り替え**: 文庫本スタイルの「縦書き」と、Webスクロールに適した「横書き」を瞬時に切り替え可能。
- **読書進捗の自動同期**: 縦横を切り替えても、読んでいた位置（スクロール率）をそのまま維持。
- **直感的なページ送り**: 画面タップ、ボタン、マウスホイール、キーボードショートカット（`←`/`→` や `↓`/`↑`）で軽快にページめくり。

### 2. 🖋️ 日本のWeb小説・出版記法に対応
- **ルビ（振仮名）表示**: カクヨム形式（`｜漢字《かんじ》`）および自動漢字ルビ（`漢字《かんじ》`）の両方に対応。
- **傍点（圏点）強調**: `《《強調したい文字》》` で文字の右横（横書き時は上）に傍点を表示。
- **縦中横（たてちゅうよこ）**: 縦書き時に「24時間」「15分」などの2桁数字を美しく水平配置。
- **コード表示（インライン＆ブロック）**:
  - `インラインコード` の埋め込み対応。
  - 複数行のコードブロック（```lang ... ```）は、縦書き時は行が縦に流れる縦組コード表示、横書き時は横組表示に連動。ステータス画面や手紙・システムメッセージの表現に便利です。
- **Markdownリンク**: `[リンク名](URL)` または `|[リンク名](URL)` のリンクを安全にクリック可能。

### 3. 📑 自動目次生成＆ジャンプ
- 原稿内の見出し記法（`#`, `##`, `###`）を自動解析して目次パネルを生成。
- 該当章へスムーズスクロールでジャンプし、読み始め位置がふわっと光るパルス強調演出付き。

### 4. 🎙️ 自然な音声朗読（Web Speech API）
- ボタン一つで本文を心地よく読み上げ。
- **ルビの二重読み防止**: 親文字とフリガナが重なって読まれることを防ぎ、自然な日本語として再生。
- 長文でもブラウザの読み上げが停止しない文単位チャンク分割処理。
- 設定パネルからお好みの日本語音声モデル（声質）、速度、音の高さを調整可能。

### 5. ☕ 読書環境のカスタマイズ ＆ 自動保存
- **3つのテーマ配色**:
  - 明鏡（白）：清潔感のある明るい紙面
  - 羊皮紙（セピア）：目に優しい古典的な文庫調
  - 漆黒（ダーク）：夜間や長時間の読書に最適な高コントラスト黒背景
- **フォント選択**: 「しっぽり明朝」 / 「Noto Serif JP」
- **文字サイズ・行間スライダー**: お好みの文字間隔にミリ単位で調整可能。
- **背景画像機能**:
  - サンプル背景「☕ ブックカフェ」をワンクリック適用。
  - 端末内の画像をドラッグ＆ドロップ、またはクリップボード（`Ctrl + V` / ヘッダーの貼付ボタン）から直接貼り付け。
  - 文字が読みやすくなるよう、背景の薄さ（不透明度）やぼかし強度をスライダーで微調整可能。
- **設定の永続化（localStorage）**: テーマ、フォント、文字サイズ、行間、背景、朗読設定はすべてブラウザに自動保存され、次回アクセス時にも完全復元されます。

### 6. 🚀 完全オフライン動作 ＆ 外部URL読込
- **完全オフライン対応**: 外部CSSフレームワーク（Tailwind CDN等）に依存せず、すべてのスタイルをローカルの `style.css` に集約。電波の届かない飛行機内や山奥でも全く崩れません。
- **外部原稿の直接読み込み**: URLパラメータ（`?url=https://gist.github.com/.../raw`）を付けることで、GitHub Gist や外部Markdownを直接展開。
- **ZIP一括保存**: 画面右上の「保存 (.zip)」ボタンから、リーダー一式を丸ごとZIPファイルでダウンロード可能。

## 🛠️ 使い方

1. **通常起動**:
   - `japanese_novel_vertical_reader.html` を任意のWebブラウザ（Chrome, Edge, Safari, Firefox等）でダブルクリックして開きます。
2. **手持ちの原稿を読む**:
   - お手元の Markdown または テキストファイル（`.md`, `.txt`）をブラウザ画面上に**ドラッグ＆ドロップ**するか、ヘッダーの「開く」ボタンから選択します。
3. **外部原稿を直接指定して開く**:
   - ブラウザのURL末尾に `?url=<MarkdownのRawURL>` を付与してアクセスすると、外部原稿を自動的に読み込んで開きます。
   - 例: `japanese_novel_vertical_reader.html?url=https://gist.githubusercontent.com/.../raw/novel.md`
